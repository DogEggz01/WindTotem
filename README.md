# WindTotem
*Disclaimer: This mod is made with ChatGPT 6.0 Astra*
- Add Wind Totem, smaller version of the wind controller on top of the Dead Cove. You can take it onto your ship.
  - Interact with the orb to start using. Orb direction decide wind direction. Orb distance from the totem base decide wind base speed.
- You need to do a quest to get this item. Quest start at the NPC facing the Dead Cove bay beside original wind controller.
  - You can only finish this quest once.
- Unlike original wind controller. After let go of the wind totem's orb, the wind will maintain the direction and wind speed for one minute before it game can change it.
- Wind totem change the base wind magnitude, at farest distance to the totem base, it will set the base magnitude to 18 knots.
  - Gust is not affected by this.
- Light cannot be turned off.
