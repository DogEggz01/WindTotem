# WindTotem
*Disclaimer: This mod is made with ChatGPT 6.0 Astra and opus 5.5*

**This Item is very CHEATY**
- Add Wind Totem, smaller version of the wind controller on top of the Dead Cove. You can take it onto your ship.
  - Interact with the orb to start using. Orb direction decide wind direction. Orb distance from the totem base decide wind base magnitude.
  - Maximum wind base magnitude is 18 (vanilla max). Gust is not affected by this item.
- You need to do a quest to get this item. Quest start at the NPC facing the Dead Cove bay beside original wind controller.
  - You can only finish this quest once.
- Unlike original wind controller. After letting go the wind totem's orb, the wind will maintain the direction and wind speed for one minute before game can change it.
- Light cannot be turned off.
